# Quantara 0.4.0 Android Preview

## وضعیت داده

- مسیر فعال برنامه قیمت و کندل واقعی بازار Futures را از Endpointهای عمومی Bitunix می‌گیرد.
- داده با polling دوره‌ای هر ۶۰ ثانیه و فقط هنگام بازبودن برنامه تازه می‌شود؛ WebSocket و پایش پس‌زمینه هنوز فعال نیست.
- تحلیل فقط کندل‌های بسته‌شده را مصرف می‌کند. TradingView Lightweight Charts موتور رسم نمودار است و منبع فید قیمت نیست.
- API Key، حساب خصوصی، ارسال سفارش و برداشت در این نسخه وجود ندارد.

## تغییرات محصول

- فارسی زبان پیش‌فرض باقی مانده است.
- تغییر فوری فارسی/انگلیسی و RTL/LTR بدون ری‌استارت اضافه شد.
- زبان و ظاهر انتخاب‌شده در Android ذخیره و پس از اجرای مجدد بازیابی می‌شوند.
- صفحه صرافی به پروفایل و تنظیمات ارتقا یافت: زبان، ظاهر، مدیریت سرمایه، اتصال‌ها، امنیت و اطلاعات نسخه.
- وضعیت اتصال از یک نشان ثابت به حالت‌های درحال اتصال، تازه‌سازی، تازه، با تأخیر و دردسترس‌نبودن تبدیل شد.
- برچسب‌های کاربرمحور `Owner Alpha`، «پیشنهاد آزمایشی» و نام نصب `Quantara Alpha` حذف شدند.
- نمودار خلاصه Semantics قابل‌خواندن برای TalkBack دریافت کرد.

## مرز نسخه

این Preview برای ارزیابی شخصی تحلیل بازار است و توصیه مالی یا سامانه اجرای معامله نیست. بسته Android برای نصب امن در کنار نسخه قبلی همچنان از application ID جداگانه استفاده می‌کند.
