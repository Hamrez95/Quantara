# Quantara 1.2.0-rc.2 known limitations

- Android remains an internal alpha-identity build and is not store-signed with the permanent production key.
- Windows is distributed as an unsigned internal ZIP.
- Public realtime monitoring is foreground-owned; closing the app or PWA tab stops that runtime.
- A quarantined stream remains excluded until the next app bootstrap/resume. Healthy streams continue, but degraded health must be reviewed.
- `Running` means entries are enabled, not that a position must open immediately. Strategy agreement, freshness, entry-zone price, affordability, exchange rules, isolated margin, full stop and all three targets must pass.
- `Managing only` intentionally blocks entries. RC2 adds explicit rearm only when zero managed positions are open; it never re-arms automatically.
- The always-on server execution mode remains locked.
