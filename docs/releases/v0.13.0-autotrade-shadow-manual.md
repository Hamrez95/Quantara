# Quantara 0.13.0 — Auto Trade shadow/manual foundation

## Included in this loop

- staged operating modes for read-only, shadow, manual approval, canary,
  restricted auto, paused and circuit-breaker states;
- a fail-closed order planner that consumes current Bitunix account equity,
  instrument precision and Quantara setup metadata;
- risk sizing from equity, configured risk, stop distance, fees and slippage;
- deterministic client IDs for retry/idempotency work;
- exchange tick/step/minimum/maximum and maximum-leverage enforcement;
- primary-setup, timeframe-conflict, signal-age, account-age, stream-health,
  allow-list, existing-exposure, concurrent-position, daily-loss, slippage,
  margin-availability and total-margin gates;
- manual plans remain `awaitingApproval`; shadow plans never submit orders;
- isolated margin is the only modeled margin mode.

## Still disabled

- REST order submission, cancellation or modification;
- leverage/margin-mode mutation at the exchange;
- protective TP/SL placement;
- private WebSocket order-state transitions;
- live canary and restricted automatic execution;
- withdrawals and transfers.

This loop creates deterministic plans and rejection reasons. It cannot place a
real order. Live execution remains blocked until order lifecycle, reconciliation,
protective-stop verification, audit logging, kill switch and physical canary
acceptance are implemented.
