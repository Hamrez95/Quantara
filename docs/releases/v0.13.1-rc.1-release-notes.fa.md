# Quantara 0.13.1-rc.1

وضعیت: Release Candidate داخلی برای پذیرش فیزیکی؛ نه Stable عمومی و نه Live-ready نامحدود.

## تغییرات اصلی

- جلوگیری از سطح خاکستری و اسکرول بی‌انتها در Setups با Recovery محدود `Q-UI-001`.
- قالب‌بندی Fail-safe برای NaN و Infinity.
- پیام شفاف سرمایه ناکافی پیش از Start اجرای محلی.
- پایش فرضی سرنوشت همه پیشنهادها، حتی پیشنهادهای گرفته‌نشده یا نمادهای حذف‌شده از Watchlist.
- خروج فرضی 35٪ در TP1، 35٪ در TP2 و 30٪ Runner.
- حفظ سود بخش‌های بسته‌شده در سناریوی TP سپس Stop.
- بازکردن Analysis روی نماد و تایم‌فریم دقیق پیشنهاد.
- Overlay تاریخی Entry/SL/TP فقط با داده معتبر و همسان.
- نسخه Android: `0.13.1+17`.
- Flutter و PWA CI با Flutter `3.44.8` ثابت شده‌اند.

## مرز ایمنی

- اتصال Bitunix هیچ سفارشی ثبت نمی‌کند.
- Local Live فقط با Start صریح و محدودیت Canary فعال می‌شود.
- Server Auto قفل است.
- برداشت/انتقال، Cross Margin خودکار، Martingale، Averaging Down و افزایش استاپ وجود ندارند.
- نتیجه فرضی سیگنال با P/L واقعی حساب مخلوط نمی‌شود.

## موارد لازم پیش از Promotion

- عبور CI کامل و Android API 34/35/36 روی SHA نهایی.
- عبور چک‌لیست فیزیکی سامسونگ.
- ساخت هویت و امضای دائمی Android برای Stable عمومی.
- انتشار Hash و Fingerprint و اثبات Upgrade بدون حذف داده.
