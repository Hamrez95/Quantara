# Quantara 0.13.0 — unattended live execution draft

## Product contract

After one explicit Start action, an always-on server—not the Android process—owns
signal scanning, risk sizing, Bitunix order submission, protective SL/TP
verification, partial exits, reconciliation, circuit breakers, and the morning
report. Stop immediately disarms new entries and either protects existing
positions or reduce-only closes Quantara-owned exposure.

## Implemented foundation

- authenticated status/start/stop server endpoints;
- idempotent Start/Stop state transitions and circuit breaker;
- official Bitunix REST and private-WebSocket signing;
- signed futures account, position, order, leverage, margin-mode, and order
  transport;
- private balance/order/position/TP-SL stream protocol and reconnecting client;
- Flutter always-on server configuration in secure storage;
- independent Start and Stop controls with symbol, timeframe, leverage, daily
  loss, and concurrency settings;
- fake transport and deterministic domain tests.

## Mandatory gates before a real-money release

- durable PostgreSQL state and append-only execution audit;
- encrypted server credential vault with trade-only permission validation;
- backend Strategy Engine parity and closed-candle scanner;
- REST/private-WebSocket order and position reconciliation;
- partial-fill and missing-stop emergency protection;
- staged TP1/TP2/runner management and reduce-only exits;
- morning report and risk/circuit-breaker visibility;
- Trader Agent fake-exchange soak, restart, and chaos scenarios;
- deployed always-on server with TLS, monitoring, backups, and kill switch;
- Shadow, manual approval, and one-symbol tiny-risk physical canary evidence.

The branch remains Draft and live capability remains fail-closed until every gate
above is complete. No withdrawal, transfer, martingale, averaging down, stop
widening, or initial cross-margin automation is permitted.
