# Quantara 0.2.0

## Stable scope

- Persian RTL Android and PWA cockpit with responsive mobile and desktop navigation.
- Deterministic candlestick charts for 15m, 1h, 4h and 1D.
- Explainable support/resistance zones, role changes, volatility and interval direction.
- Read-only ASP.NET Core endpoints at `/health` and `/api/v1/cockpit`.
- Strict Flutter validation of API schema, freshness, safety locks and account reconciliation.
- Clearly labelled offline deterministic fallback when the API is not configured or temporarily unreachable.
- Release builds for web/PWA and Android, including configured and unconfigured API compile gates.

## Safety boundary

The API is GET-only and exposes deterministic demo data. It has no exchange credentials, order submission, withdrawals or execution authority. The client rejects responses that claim real-money or order authority. Live trading remains unavailable.

## Known limitations

- Market candles and cockpit values are deterministic fixtures, not live exchange observations.
- Support/resistance strength is a bounded heuristic, not a profitability claim or trading instruction.
- The Android APK is suitable for direct testing; store distribution signing is a separate owner-controlled release step.
- Paper/shadow execution, official Bitunix read-only data and restricted live release gates remain future milestones.

## Validation gates

- .NET restore, formatting, Release build and tests.
- Read-only API process smoke test and HTTP contract validation.
- Flutter formatting, analysis and widget/unit tests.
- Web/PWA and Android Release builds with and without an HTTPS API origin.
