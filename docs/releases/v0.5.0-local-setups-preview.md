# Quantara 0.5.0 local setups preview

## Scope

This preview turns the read-only market radar into a local setup workflow while
preserving the project safety boundary: Quantara still has no exchange API key,
real order placement, auto-trading or withdrawal capability.

## Included

- scans every watchlist symbol on closed `15m`, `1h` and `4h` candles
- keeps healthy symbol/timeframe results when another scan item fails
- validates one-tick Bitunix rounding drift using the precision present in the
  source price values
- creates deterministic Long/Short setup identifiers from symbol, timeframe,
  direction and closed-candle fingerprint
- provides entry range, stop loss and TP1/TP2/TP3
- calculates risk-sized asset units, position notional, conservative suggested
  leverage and required entry margin
- caps leverage by stop distance, volatility and structure evidence; increasing
  leverage does not increase the risk-sized position
- adds a device-local “Taken” journal checkbox
- adds opt-in Android notifications for newly discovered setups and deduplicates
  alerts for the same closed candle
- documents the active `Structure Zones v1.1` deterministic strategy and adds
  contextual information sheets to technical sections
- adds a guided English PowerShell release builder for APK, AAB, Web and
  platform-specific desktop/mobile outputs

## Notification boundary

Local setup alerts are evaluated after a successful app scan. Android can show
the notification while the app is active or resident, but this preview does not
promise continuous monitoring after the operating system stops the app.
Reliable closed-app, 24-hour monitoring still requires a backend scanner and
push delivery.

## Risk boundary

The leverage value is a sizing aid, not a liquidation-price guarantee. Actual
exchange maintenance margin, fees, funding, slippage, gaps and liquidity can
increase losses. The user must verify all values in the exchange before acting.
