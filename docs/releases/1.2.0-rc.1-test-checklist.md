# Quantara 1.2.0-rc.1 test checklist

## Automated gates

- [ ] Flutter 3.44.8 and Dart 3.12.2 versions confirmed
- [ ] Canonical format
- [ ] Strict analyzer
- [ ] Full Flutter/widget/safety tests
- [ ] General repository and .NET tests
- [ ] PWA build and release-bundle validation
- [ ] Android API-configured build
- [ ] Android universal APK
- [ ] Android arm64 ABI APK
- [ ] Manifest safety declarations
- [ ] Universal and arm64 16 KB ZIP alignment
- [ ] Android API 34 cold start
- [ ] Android API 35 cold start
- [ ] Android API 36 cold start
- [ ] Native Windows x64 build and ZIP artifact

## Physical Samsung test

- [ ] Clean install succeeds
- [ ] Upgrade from the previous alpha build succeeds
- [ ] Cold start and warm start succeed
- [ ] Background/resume does not duplicate candidates or notifications
- [ ] Network loss and Wi-Fi/mobile-data switching recover safely
- [ ] Realtime health shows the expected stream/shard state and latency
- [ ] Journal and Signal Inbox survive restart
- [ ] Chart opens the correct signal symbol and timeframe
- [ ] Local Live remains disarmed after restart
- [ ] Notification permissions and timing are acceptable
- [ ] No secret appears in logs or screenshots

## Windows test

- [ ] ZIP extracts and launches on the target Windows PC
- [ ] Window resizing and responsive desktop layout are stable
- [ ] Keyboard navigation and large text are usable
- [ ] Public realtime monitoring pauses safely when the app closes
- [ ] Unsigned-build warnings are recorded as an RC limitation

## PWA test

- [ ] Initial load and normal refresh succeed
- [ ] Persian RTL and English LTR work
- [ ] Responsive desktop/mobile layout works
- [ ] Closing the tab clearly stops foreground-only realtime monitoring

## Promotion decision

Stable promotion is allowed only after every automated gate is green and the physical Samsung upgrade/install checklist has been accepted. Until then the release PR to `main` remains unmerged.
