# Quantara 1.2.0-rc.1 release notes

Build number: `120`

This release candidate is the first testable Quantara build that combines the audited public realtime market pipeline, durable Signal Inbox and Journal projections, guarded Local Live controls, PWA packaging and a native Windows bundle on one current `dev` history.

## What to test first

1. Launch the Android app and confirm the health strip moves from bootstrap/connecting to live monitoring.
2. Verify the configured watchlist streams 5m, 15m, 1h and 4h without requiring manual refresh.
3. Open a signal on the chart and confirm symbol, timeframe and signal context are selected automatically.
4. Close and reopen the app; verify Journal, Signal Inbox metadata and taken/not-taken state survive restart.
5. Confirm Local Live remains disarmed after restart and requires the explicit safety confirmations.
6. Test Persian RTL and English LTR, large text and the responsive desktop layout.
7. Run the Windows ZIP and verify keyboard navigation, window resizing and public realtime health.
8. Test the PWA while online and after a normal page refresh; closing the tab intentionally stops realtime monitoring in this RC.

## Release boundary

This is an internal Release Candidate, not a Stable or store-published build. The Android package remains the alpha identity and the Windows ZIP is unsigned. Real-money authority remains guarded and separate from the public realtime runtime.
