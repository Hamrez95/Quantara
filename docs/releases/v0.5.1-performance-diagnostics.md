# Quantara Android 0.5.1 — Performance & Diagnostics

## Outcome

This release removes unnecessary full-market rescans from ordinary symbol and
timeframe navigation and makes every radar pass observable.

## Changes

- Symbol and `15m`/`1h`/`4h` timeframe changes are projected immediately from
  the current immutable snapshot when the requested analysis is already present.
- Closed-candle analyses are cached by symbol/timeframe until the next candle
  can close. A periodic refresh still retrieves live public ticker values.
- The radar reports analyzed charts, elapsed scan time, cache hits, market
  request count and explicit rejection counts.
- Wait outcomes are classified as weak direction, incomplete zones,
  insufficient reward-to-risk or unavailable data.
- A missing uncached timeframe still fails closed and leaves the last valid
  selection on screen.

## Safety boundary

The strategy remains `Structure Zones v1.1`. This release does not claim a
profitable strategy, lower the `1.6` reward-to-risk gate, place orders or add
exchange credentials. Market-regime and new strategy modules remain research
work until they pass historical and forward validation.

## Validation

Run from `src/client/quantara_app`:

```bash
flutter pub get
dart format --output=none --set-exit-if-changed lib test
flutter analyze --fatal-infos
flutter test
flutter build apk --release
```
