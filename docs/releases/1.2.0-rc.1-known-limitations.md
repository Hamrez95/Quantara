# Quantara 1.2.0-rc.1 known limitations

## Monitoring lifecycle

- Realtime monitoring in this RC is foreground-only. Closing the Android app, Windows application or browser tab stops the public realtime runtime.
- Android background/foreground-service behavior beyond cold-start and manifest safety still requires physical Samsung validation.
- PWA background continuity is constrained by browser lifecycle and is not promised in this RC.

## Distribution and signing

- Android artifacts use the alpha package identity and CI/internal signing. They are not Play Store production artifacts.
- The Windows ZIP is unsigned and intended for internal testing. SmartScreen reputation and signed installer upgrade behavior are not validated.
- `main` and Stable release remain blocked until the permanent signing and physical upgrade gates pass.

## Trading boundary

- Public realtime monitoring does not grant order authority.
- Guarded Local Live remains opt-in and must not be treated as unattended production trading.
- Withdrawal, transfer, cross margin, martingale, averaging down, duplicate entry and stop widening remain unsupported and prohibited.

## Validation still requiring the owner/tester

- Install and upgrade on the target Samsung device.
- Resume after backgrounding, network switching and device sleep.
- Notification timing and permissions on the physical device.
- Windows SmartScreen/antivirus behavior on the target PC.
- Final UX review of realtime health, Signal Inbox, chart navigation and Persian/English layout.
