## Owner-alpha stabilization

This candidate consolidates the Local Live / Guarded Auto stabilization work completed after rc.2.

### Strategy identity and evaluation

- Added a pluggable/versioned canonical strategy registry with deterministic snapshot identity.
- Bound Robot/Guarded Auto to the exact evaluated strategy/version/parameter snapshot instead of silently remapping to latest behavior.
- Added deterministic evaluation-run evidence, bounded archive retention, run-scoped scorecards, chart replay contracts and structured diagnostics.
- Kept setup/evaluation evidence separate from unrelated exchange account history; manual evaluation capital remains an explicit evaluation baseline.

### Global Pause and restart safety

- Added durable Global Pause states for running, Safe Pause, Offline Pause and explicit resume validation.
- Pause survives process restart; interrupted/corrupt persisted state fails closed and does not auto-resume scanning or entries.
- Android WorkManager callbacks re-check durable pause intent before background market/network scans and cancel queued scan work while paused.
- Safe Pause preserves only the minimum already-open exposure/protection management required by authoritative account state.

### Diagnostics and explainability

- Added stable structured events for strategy resolution, candidate/gate decisions, robot binding, evaluation lifecycle, scorecards, cleanup/replay and Global Pause lifecycle.
- Diagnostics distinguish canonical strategy rejection from execution/safety-gate rejection and continue to redact credentials/secrets.

### Release hardening

- Added a checked-in machine-readable readiness manifest, deterministic quality score, stability report and rollback/forward-recovery plan.
- Software evidence is tied to auditable CI/check/artifact IDs; release metadata cannot silently stand in for missing physical evidence.

## Safety and limitations

- No profit, win-rate or deployability guarantee is implied by evaluation statistics.
- Missing/stale account, strategy, reconciliation, protection or pause evidence remains fail-closed for opening new risk.
- No withdrawal/transfer authority or autonomous LLM trading authority is introduced.
- Production/store publication and any restricted-live release decision remain separate explicit approvals.
- Physical-device and exchange behavior must not be inferred from software CI; evidence that was not observed remains pending.
