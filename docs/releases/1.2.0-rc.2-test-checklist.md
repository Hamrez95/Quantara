# Quantara 1.2.0-rc.2 physical test checklist

## Upgrade

- Install RC2 over RC1 without clearing app data.
- Confirm API credentials, watchlist and Local Live preferences remain available.
- Confirm Local Live does not auto-arm because of the upgrade.

## Realtime health

- Open the app and wait for bootstrap.
- Confirm the health strip no longer remains at `0/0` because of `AVAXUSDT|15m`.
- A fully healthy run should show all configured streams healthy and at least one live shard.
- If Bitunix returns an unusable stream, confirm the strip reports degraded live monitoring and a non-zero quarantined count while other symbols continue updating.
- Confirm refresh, background/resume and Wi-Fi/mobile-data transitions do not create duplicate signals.

## Local Live state

- When the status is `فقط مدیریت` / `Managing only` with zero open positions, confirm `ازسرگیری ورود` / `Resume entries` appears.
- Press Resume and confirm the advanced-risk and real-money confirmation dialogs are shown again.
- Cancel either dialog and confirm entries remain disabled.
- Complete both dialogs and confirm the status moves to starting/running with entries enabled.
- When an exchange-protected position is open, confirm Resume is unavailable.
- Confirm reboot or force-stop never restores entry authority automatically.

## Execution expectations

- Running does not guarantee an immediate position: the selected strategy, timeframe agreement, entry zone, affordability, isolated-margin support, minimum quantity, complete SL and all three TP orders must pass.
- Review `گزارش اجرا` / `Execution log` when a scan does not enter; a bounded skip reason should be recorded.
- Use only the intended small-balance canary account and an API key without withdrawal or transfer permission.
