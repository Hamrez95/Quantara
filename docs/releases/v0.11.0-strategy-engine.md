# Quantara 0.11.0 — adaptive strategy engine

## Included playbooks

- Structure & Zones control strategy
- Adaptive range mean reversion using market regime, Bollinger location, RSI, ADX, trend efficiency and closed-candle reversal
- Price-action reversal at validated support/resistance using engulfing, wick rejection and liquidity-sweep evidence
- Trend Pullback using EMA structure, ATR, RSI reset, ADX/DI, relative volume and multi-timeframe alignment
- Ichimoku trend/pullback using a no-lookahead visible cloud, Tenkan/Kijun, Chikou clearance and closed-candle confirmation
- Donchian 20 breakout using ATR expansion, relative volume, ADX/DI and multi-timeframe alignment

## Risk controls

- paper-trading analysis only; no exchange order placement
- maximum loss derived from configured account risk
- estimated 0.20% round-trip costs included
- volatility- and confidence-capped leverage
- three strategy-specific R targets
- closed-candle data only
- explicit market disorder and insufficient-confirmation no-trade outcomes

## Android reliability

- deferred WorkManager initialization outside the launch-critical path
- periodic OS-scheduled opportunity scans and deduplicated local notifications
- universal and arm64-v8a APKs
- 16 KB ZIP alignment checks
- Android API 34, 35 and 36 cold-start smoke tests

## Validation policy

Passing synthetic and regression tests proves deterministic implementation behaviour, not future profitability or a guaranteed win rate. Strategy versions remain visible in the signal journal so paper outcomes can be evaluated separately before any later automation decision.
